# Practice

Each folder is one brief with its files, set up the way the real one will arrive: a written brief and some material.

| Folder | Brief |
|---|---|
| `01-deck-copy/` | Get a client deck's copy ready to send |
| `02-poster-resize/` | Turn one film poster into a pack of sizes |

## Running one

1. Do not open the folder until you start the timer.
2. Start a 2-hour timer. Follow `docs/RUN-OF-SHOW.md`.
3. Copy `plan.blank.ts` over `plan.ts`.
4. Copy the brief's files into `data/` so the tool can read them.
5. Build. Tag `v1`, `v2`, `v3`.
6. Afterwards, spend 30 minutes writing down what slowed you down, and fix those things in the starter.

Everything here is invented: the agency, the clients, the film and the people.
